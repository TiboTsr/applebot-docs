Démarrage rapide pour les administrateursQuick start for server admins

L’assistant /setup configure Pallas Radar pas à pas. Il suffit d’être administrateur du serveur.The /setup wizard configures Pallas Radar step by step. You just need to be a server administrator.

1

/setup

Tapez la commande dans n’importe quel salon : l’assistant répond avec un message visible par vous seul.Type the command in any channel: the wizard replies with a message only you can see.

2

Salon d’annoncesChannel

Sélectionnez le salon dans un menu natif. Pallas Radar contrôle immédiatement qu’il peut y envoyer des messages et des embeds.Pick the channel from a native menu. Pallas Radar immediately checks it can send messages and embeds there.
